# Per-file data for veldin (tools/split_data.py, docs/veldin.md "Per-file data").
#

# retail bytes of the data segment there (.lit 0x1D5680.., .data 0x2A4480..).

# variables and constants the code reaches through $gp), .lit4 / .lit8 (GNU as
# float literals), .data / .bss. The size comes from the file's object.
#
# section   address     source file
